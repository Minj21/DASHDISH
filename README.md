# DASHDISH

Portfolio fork of the collaborative `DASHDISH` Flutter project originally hosted at:
https://github.com/taalabdoulie31-stack/DASHDISH

## Project Overview

DASHDISH is a Flutter food-ordering application. The project includes authentication screens, home and landing screens, food category pages, cart and checkout flows, favorites, profile screens, a map page, Firebase configuration, and image assets for menu items.
